# Программа под человека: анкета и генератор (черновик для обсуждения)

Статус: **черновик**, ноябрь 2026. Выбран вариант D (обсуждение 12 ноября): стартовая программа по правилам,
дальше её ведёт уже готовая аналитика (прогрессия, плато, перегрузка, разгрузка), пересмотр каждые 6 недель.
Числа в правилах — **наш выбор внутри диапазонов из источников**; где источник прочитан только в пересказе или
по аннотации — помечено. Перед кодом каждое правило подтверждаем или правим.

## 1. Что уже решили

- Одна анкета для всех. «Новичок / профессионал» — не две ветки: опытный может нажать «Я сам» и пропустить.
- Программа фиксированная (комплексы + план недели), человек её видит и может посмотреть, почему так (ссылки на правила).
- Через 6 недель — «Пересмотреть программу»: короткая повторная анкета, новые объёмы.
- **Замена упражнения** — только внутри своего семейства движения (те же мышцы), **сразу в программе**
  («только сегодня» нет), **один раз на каждое место** в программе — для начала, проверим в зале.
  Не своё семейство — нельзя: иначе программа превращается в кашу.
- **«Больше не предлагать»** — упражнение уходит в исключения, генератор его не возьмёт.
- 5 дней — «тяни / толкай / ноги + верх / низ». Цели — три: мышцы, сила, похудение (без «Здоровья и тонуса»).
- Ответы анкеты приходят с фронта; опыт и прочее, что относится к человеку, записываем и в профиль.
- Ограничения (колени, поясница, плечи) оставляем, источник ищем отдельно.
- Свои комплексы человека **не трогаем**: программа появляется рядом. План недели «Начать программу» **заменяет**
  днями программы (решили 13 ноября: комплексы остаются, расставить их по дням заново — минута).
- Недостающие для программы упражнения записываем в «Нет в каталоге» на странице ревизии каталога (docs/catalog.md).
- Когда предлагать: сразу после регистрации (онбординг, вариант A — по шагу на экран); «Я сам» — пропустить.
  Пройти позже — только в профиле, раздел «Программа тренировок». На главной строки нет (добавим, если понадобится).

## 3. Правила генератора

| Правило | Что делаем | Источник |
|---|---|---|
| **П1. Сплит** | 2–3 дня → всё тело каждую тренировку; 4 дня → верх/низ × 2; 5 дней → тяни / толкай / ноги + верх / низ. Каждая мышца — **не реже 2 раз в неделю** | ACSM 2009: новичок 2–3 дня, средний 3–4, опытный 4–5 [Ratamess 2009]; 2 раза в неделю на мышцу лучше 1 при равном объёме [Schoenfeld 2016] |
| **П2. Объём** (рабочих подходов на мышцу в неделю, старт) | новичок 8–10 · средний 10–14 · опытный 14–18; на пересмотре +2–4, если прогресс есть и перегрузки не было | от ~10 подходов, дальше больше = лучше с убывающей отдачей [ACSM 2026, пересказ]; [Pelland 2024, препринт] |
| **П3. Подходов в упражнении** | 2–4 (новичок 2–3) | 1–3 для новичков [Ratamess 2009] |
| **П4. Повторы по цели** | Мышцы: 8–12 (изоляция 10–15) · Сила: базовые 4–6, остальные 8–12 · Похудение: 10–15 | 8–12 ПМ новичкам; для силы — тяжёлые 1–6 [Ratamess 2009]; сила лучше от ~80% 1ПМ, рост мышц мало зависит от веса при равном объёме [ACSM 2026, пересказ; Swinton 2024] |
| **П5. Близость к отказу** | 1–3 повтора в запасе; новичку 2–3 (сначала техника) | до отказа не обязательно, 1–2 в запасе не хуже [ACSM 2026, пересказ]; для роста мышц ближе к отказу лучше, для силы разницы нет [Robinson 2024] |
| **П6. Отдых между подходами** | базовые 2–3 мин, изоляция 1–2 мин | больше 60 с — небольшой плюс, больше 90 с — разницы не видно [Singer 2024]; базовые ≥ 2–3 мин [Ratamess 2009] |
| **П7. Порядок** | сначала многосуставные, потом односуставные; крупные мышцы раньше мелких | [Ratamess 2009] |
| **П8. Выбор упражнений** | по семействам движения. Всё тело: присед/выпад + наклон + жим лёжа + тяга (гориз./верт., чередуем) + жим вверх, остальное — изоляция по времени. Верх: жим лёжа, тяга к поясу, жим вверх, тяга сверху + руки/дельты. Низ: присед, наклон, выпады, сгибание ног, икры, пресс. Во второй день недели — другое упражнение того же семейства | систематическая вариация полезна, хаотичная — мешает [Kassiano 2022]; свободные веса и тренажёры дают одинаковый рост мышц [Haugen 2023] |
| **П9. Время → число упражнений** | 45 мин ≈ 4–5 · 60 мин ≈ 5–6 · 75+ ≈ 6–7 | **наша оценка**: ~3 подхода × (подход + отдых 2 мин) ≈ 9–10 мин на упражнение |
| **П10. Прогрессия** | двойная: все подходы на верхней границе повторов (два раза подряд) → +вес на шаг снаряда (штанга 2,5 кг, гантели 1–2 кг, тренажёр — его шаг); повторы снова с нижней границы | +2–10% веса, когда делаешь на 1–2 повтора больше цели два раза подряд [Ratamess 2009]; шаги весов у нас уже есть (`WEIGHT_STEP`) |
| **П11. Пересмотр и разгрузка** | программа на 6 недель; перегрузка → разгрузка (уже есть) | разгрузка раз в 4–6 недель [Bell 2023, у нас в references.md №4] |
| **П12. Похудение** | силовые те же (сохранить мышцы) + совет: 150–300 мин умеренного кардио в неделю; калории — позже, блок «питание» | **по памяти, проверить**: рекомендации ВОЗ 2020; силовые на дефиците сохраняют мышцы [обзор Frontiers in Nutrition 2025 — не читал полностью] |
| **П13. Ограничения** | колени → без выпадов и глубоких приседов со штангой, жим ногами/разгибание оставить на усмотрение; поясница → без становой и наклонов со штангой, приседа со штангой (замена: тренажёры, гиперэкстензия); плечи → без жима из-за головы и брусьев | **наша консервативная логика**, не медицинский совет; подкрепить источником перед кодом (открытый вопрос) |
| **П14. Замена** | только своё семейство, доступный снаряд, насовсем в программе, 1 раз на место; «больше не предлагать» | выбор снаряда — второстепенная переменная [ACSM 2026, пересказ; Haugen 2023]; частая смена упражнений мешает [Kassiano 2022] |

## 4. Каталог: что проверить до кода

- Дома с гантелями нет **тяги сверху** (нужен турник или тренажёр) и **сгибания ног** — генератор подставит
  ближайшее (тяга гантели в наклоне, румынская тяга с гантелями) и честно скажет об этом.
- У **жима вверх** нет варианта в тренажёре, у **наклона** — с гантелью только один. Для замен по семейству
  мало вариантов — возможно, добавить пару упражнений в каталог (миграция).

## 5. Как устроить в коде (набросок)

- Генератор — в **workout-service**: там каталог, комплексы и план недели. Результат — обычные комплексы
  (`workout_templates`) + план недели, помеченные «из программы» (`program_id`).
- Новые таблицы: `programs` (ответы анкеты, дата старта, дата пересмотра, активная/архив),
  `program_slots` (место в программе: день, порядок, семейство, упражнение, сколько раз меняли),
  `exercise_exclusions` («больше не предлагать»).
- Уровень подготовки живёт в user-service; workout-service получает его из `UserProfileUpdatedEvent` (Kafka)
  или фронт передаёт его в запросе генерации — **обсудить**.
- Генератор — чистый класс без Spring (`ProgramGenerator`: анкета + каталог → программа) — легко покрыть тестами,
  каждое правило П1–П14 — отдельный метод с тестом.

## 6. Решено 13 ноября (бывшие открытые вопросы)

1. 5 дней — тяни / толкай / ноги + верх / низ.
2. Целей три.
3. Анкета — с фронта, нужное записываем в профиль.
4. Ограничения — оставить, источник найти.
5. Старые комплексы и план — оставить рядом.

Дальше: внешний вид — макеты на холсте «Vegas — анкета и программа»
(https://claude.ai/artifact/9ATqGjH8DjRSHWKnw6N6AU): анкета в двух вариантах (A — шаг за шагом, B — одной страницей),
«Ваша программа», день программы, замена упражнения, входы на главной и в профиле.
