Макеты экранов и карта переходов между ними.

- `Структура дневника Vegas.canvas` — карта экранов (открывается в Obsidian)

- `N_Название.png` — отдельные экраны: **раскладка**, оформление — по [STYLEGUIDE.md](STYLEGUIDE.md)
- `STYLEGUIDE.md` — единый стиль (вариант C, светлая и тёмная темы)
