# Стиль Vegas (вариант C)

**Главный справочник — дизайн-система Vegas** (claude.ai): https://claude.ai/artifact/YJT7gM19i2o2dBWFhbuVtc —
токены, шкала шрифта, компоненты с примерами в двух темах и правила. Добавляем или меняем экран — сверяемся с ней,
чтобы приложение не «расползалось». Аудит всех экранов (ноябрь 2026): https://claude.ai/artifact/9cCLosdETT2WfWidcUAsw5

Единый стиль для всех экранов. Старые макеты `N_Название.png` — это **раскладка** (что где стоит),
а не оформление: шрифты, цвета и скругления берём только отсюда.

Источник правды в коде — `frontend/src/styles/tokens.css`.

## Правила

1. **Цвета, шрифты, скругления, отступы — только через токены** `var(--...)`.
   Никаких `#111827` и `border-radius: 13px` в компонентах: иначе темы и страницы разъедутся.
2. **Экраны собираются из `components/ui`**: `PageHeader` (шапка страницы), `SectionLabel` (подпись раздела),
   `Card`, `StatTile` (два размера), `ListRow`/`ListRowGroup` (строки списка), `Button`, `Badge`, `SegmentedControl`.
   Нужна новая разновидность — добавляем вариант в общий компонент, а не рисуем похожий по месту.
3. Каждый новый экран проверяем **в обеих темах** и **на ширине телефона (390px)**.

## Типографика

| Что | Шрифт | Токен |
|---|---|---|
| Заголовок страницы (`PageHeader`) | Unbounded 700 | `--text-h1` 40px (28px на телефоне) |
| Главная цифра, крупная плитка | Unbounded 700 | `--text-num` 32px |
| Заголовок внутри карточки | Unbounded 700 | `--text-lg` 20px (`--text-xl` — то же) |
| Цифра компактной плитки, значение в строке | Unbounded 700 | `--text-num-md` 20px |
| Основной текст | Onest 400–600 | `--text-md` 16px |
| Подписи, вторичный текст | Onest | `--text-sm` 14px, цвет `--text-muted` |
| Сноска*, подпись раздела ПРОПИСНЫМИ (`SectionLabel`) | Onest | `--text-xs` 12px. Меньше — нигде |

Обращение к пользователю — на «вы» во всём интерфейсе. Числа — через запятую: «79,2 кг».

## Форма

- Скругления: карточки, плитки, окна **24px**, элементы внутри карточки **16px** (`--radius-inner`), кнопки/бейджи/переключатели — «пилюля».
- Кнопки и поля: высота **52px**, кликабельные элементы не меньше 44px.
- Отступы — шаг 4px: 4, 8, 12, 16, 24, 32, 48.

## Цвет и смысл

| Роль | Светлая | Тёмная | Где |
|---|---|---|---|
| Фон | `#EEF1F5` | `#0B0F17` | страница |
| Карточка | `#FFFFFF` | `#161B26` | обычные блоки |
| Акцентная карточка | `#111827` | `#F9FAFB` | одна главная цифра экрана, основная кнопка |
| Оранжевый (заливка) | `#C2410C` | `#C2410C` | риск перегрузки, бейдж «перегрузка» — белый текст |
| Оранжевый (линии) | `#EA580C` | `#FB923C` | линия «ты» на графике, иконки подсказок |
| Нейтральный бейдж | `#E5E7EB` | `#2D3546` | «плато», переключатели |

Оранжевый — только для того, что требует внимания (риск, твоя линия на графике). Не красим им всё подряд.

## Тема

`Светлая / Тёмная / Как в системе` (Профиль). Выбор хранится в браузере (`localStorage`, ключ `vegas.theme`),
по умолчанию — как в системе. Сохранение в профиле на бэкенде — вместе с мобильным приложением.
