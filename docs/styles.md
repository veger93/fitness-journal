## A · Стекло
Светлый воздух: матовые карточки поверх мягких цветных бликов, тёмные кнопки, один синий акцент.
- Фон `#eaeef6` + размытые блики `#9fc4ff`, `#ffc4e3`, `#a6efd3`, `#c9c2ff` (медленно плывут).
- Карточка: белый 66% + `backdrop-filter: blur(18px) saturate(1.5)`, рамка белая 90%, тень `0 10px 28px rgb(16 19 42 / .08)`.
- Текст `#10132a`, вторичный `#555c78`; кнопка `#10132a` / белый; акцент `#3350f5`; рекорд `#d81f6a`; успех `#0b7a52`.
- Главная карточка (серия, кольцо): тёмное стекло `rgb(16 19 42 / .92)`, кольцо `#7ef0c7`.
- Шрифт: Manrope 500–800. Радиус 24 / 14. H1 26px, H2 17px, цифры 26px.
- Движение: карточки всплывают (rise), кольца/полоски заполняются, графики прорисовываются.

## B · Метро
Гамма Metrofitness (снята с chelyabinsk.metrofitness.ru): чёрный, жёлтый только на главном.
- Фон `#0a0a0a`, карточка `#1a1a1a`, вторая поверхность `#2b2b2b`, рамка `#303030`.
- Текст `#f7f7f7`, вторичный `#a3a3a3`; жёлтый `#fff200` с текстом `#0c151a`; успех `#3ddc84`.
- Кнопка жёлтая с нижней гранью `0 5px 0 #b3a900`; вторая кнопка — жёлтый контур.
- Шрифт: заголовки Unbounded 800 ПРОПИСНЫМИ (H1 19px, H2 13.5px), текст Onest. Радиус 18 / 12.
- Мотивация: серия с огоньком, уровень и очки, конфетти на рекорде.
- Движение: всё пружинит (pop), огонёк покачивается.

## C · Тетрадь
Дневник от руки: бумага в клетку, синяя ручка, маркер, стикеры.
- Фон `#fbfaf5` + клетка 20px `rgb(27 42 107 / .1)`; карточка `#fffef9`, рамка 2px `#1b2a6b`, неровный радиус `255px 14px 225px 14px / 14px 225px 14px 255px`.
- Текст и кнопка `#1b2a6b`; маркер `#ffe14d`; красная ручка `#d7263d`; зелёный `#1c7c3c`.
- Главная карточка — жёлтый стикер `#ffe97a` со скотчем, повёрнут на −1,2°.
- Шрифт: заголовки и цифры Caveat 700 (H1 36px, H2 25px, цифры 34px), текст Golos Text.
- Движение: маркер проводится под заголовком, стикер приклеивается, графики рисуются как ручкой.

## Как стили устроены в приложении

- Выбор: Профиль → «Оформление» → «Стиль». Хранится в браузере (`localStorage`, ключ `vegas.skin`), по умолчанию «Классика».
- Код: `frontend/src/theme/skin.ts` (список стилей), `ThemeProvider` ставит `<html data-skin="...">`, ранний скрипт в `index.html` — чтобы не мигало.
- Вид: `frontend/src/styles/skins/<стиль>.css` — сначала токены, потом детали по классам-крючкам `ui-*` из общих компонентов (`ui-card--inverse`, `ui-btn--primary`, `ui-h1-text`, `ui-tabbar` …).
- Шрифты стиля грузятся только когда он выбран (`SKIN_FONTS`).
- Готово все три: «Стекло» и «Тетрадь» (только светлые), «Метро» (только тёмное).
- «Стекло»: карточки, списки, вкладки и окна — матовое стекло (`backdrop-filter`), за ними неподвижный слой цветных бликов (`body::before`, медленно плывёт только `transform`, без `filter: blur`). Карточки всплывают при открытии экрана. Риск — малиновый, линии графиков — синие.
- Тема у стиля с одним вариантом фиксирована: `fixedTheme` в `skin.ts`, переключатель темы для него скрыт.

### «Метро»: фон

- Неподвижное тёмное фото «Плечи со спины» с жёлтым отблеском, средняя яркость (выбрано в ленте стилей). Два слоя `body::before` (фото) и `body::after` (затемнение + отблеск) с `position: fixed`; `background-attachment: fixed` на iPhone не работает — поэтому слои.
- Карточки поверх фото полупрозрачные с размытием. На компьютере фото справа и уходит в чёрное к контенту.
- Файл: `frontend/src/assets/skins/metro/shoulders.webp` (ч/б, 900px, ~8 КБ), скачивается только в «Метро».
