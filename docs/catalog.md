# Каталог упражнений: как наполняем и проверяем

## Где проверяем
Страница «Ревизия каталога упражнений» на claude.ai (артефакт с базой, ссылка — в проекте `claude/catalog.md`).
- Группы: Тренажёры → Штанга → Гантели → Свой вес, внутри — по частям тела.
- У каждого упражнения «Всё верно» / «Есть ошибка» + текст. Отметки сохраняются сами (коллекция `reviews`,
  id документа = id упражнения), Claude читает их оттуда.
- «Нет в каталоге» — список недостающих упражнений (коллекция `missing`).
- У отметки хранится `rev` — хеш содержимого упражнения. Упражнение поменяли → «изменено — проверь снова».

## Цикл
1. Проверка и отметки (можно в зале с телефона), недостающее — в «Нет в каталоге».
2. Claude читает отметки и список, предлагает исправления.
3. Исправления и новые упражнения — **только новой миграцией** Liquibase в workout-service
   (старые файлы не трогаем), по системным упражнениям (`owner_id IS NULL`), по имени.
4. После выкладки страница ревизии перевыпускается с новым каталогом.

## Правила
- **Переименование безопасно**: история и аналитика ссылаются на id. Генератор демо (`DemoScenarios`) ищет
  упражнения по имени — при переименовании проверить его.
- **Не удаляем** упражнения — только `archived_at` (по ним могут быть тренировки).
- **Не подменяем одно упражнение другим** в тренировке: прогресс, плато и перегрузка считаются по упражнению,
  подмена смешивает истории. Нет нужного — «Своё упражнение», потом переносим в каталог.
- **Похожее, но на другом тренажёре — отдельное упражнение** (рычажная тяга ≠ тяга блока): веса несравнимы.
- Название — как говорят в зале, без брендов.
- Картинки: только Everkinetic (CC BY-SA, атрибуция в `frontend/public/exercises/LICENSE.md`).
  Нет подходящей — без картинки (заглушка). Неверная картинка хуже заглушки.

## Семейство движения
У каждого системного упражнения — `movement_pattern` (миграция 019, docs/analytics.md): похожие по движению
упражнения поддерживают силу друг друга. Новое упражнение в каталог — сразу с семейством (или NULL, если похожих нет).
На странице ревизии семейство показано в описании.

## Вес в подходе
Шаг кнопок ± зависит от снаряжения (`WEIGHT_STEP` в `frontend/src/lib/workout.ts`): штанга, гантели, свой вес —
2,5 кг; тренажёр — 1 кг и только целые (стек бывает 46, 52, 59 кг). Старый дробный вес тренажёра в подсказке
округляется (45,5 → 46).
