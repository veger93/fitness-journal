# Аккаунт: подтверждение email, «Забыли пароль?», удаление аккаунта

Согласовано: октябрь 2026. Делается в `feature/trainer` до выкладки режима тренера: клиент, получивший аккаунт
от тренера, должен иметь возможность восстановить пароль.

## Подтверждение email — код из 6 цифр

- После регистрации (и после получения аккаунта от тренера) сразу приходит письмо с кодом.
- **Приложение не блокируем**: в профиле карточка «Подтвердите email» — поле для кода,
  «Отправить код ещё раз», «Исправить email» (новый адрес + пароль, на него сразу уходит новый код).
- На главной — только намёк (`EmailVeil`): сверху тёмная вуаль, растворяющаяся вниз, с мелкой ссылкой
  «Подтвердите email, чтобы не потерять доступ →» в профиль. Появляется **после первой записанной тренировки**
  (сначала человек пробует приложение, потом уже есть что терять); в режиме тренера за клиента — нет.
- После подтверждения на месте карточки — «Email подтверждён ✓» на лёгком зелёном свечении, галочка «пишется»
  росчерком; через ~2 с растворяется, карточки ниже плавно поднимаются (`EmailConfirmed`).
- Почему код, а не ссылка: ссылку на телефоне часто открывает встроенный браузер почты, а не тот, где человек вошёл;
  код вводится прямо в приложении.

## Правила кода (EmailCodeService)

| Правило | Зачем |
|---|---|
| Живёт 15 минут | Не валяется в почте вечно |
| Действует только последний | «Отправить ещё раз» отменяет старый |
| Не больше 5 неверных попыток | 6 цифр — миллион вариантов: перебор невозможен |
| Повторно — не чаще раза в минуту | Нельзя завалить чужую почту письмами |
| В базе — SHA-256 от «userId:код» | Утечка таблицы не даёт кодов; id — «соль» |
| Код на старый адрес не подтверждает новый | Исправил email — нужен код с нового |

Письмо шлёт notification-service по событию `EmailCodeRequested` (user-events). В ленту уведомлений код не пишется.

## «Забыли пароль?»

`/forgot-password`: email → код из письма + новый пароль → вход заново.
- Код приходит **только на подтверждённый** email.
- Ответ на «Прислать код» всегда одинаковый — по форме нельзя узнать, зарегистрирован ли человек.
- После смены пароля закрываются все входы на всех устройствах (refresh-токены, причина `PASSWORD_RESET`).

## «Удалить мой аккаунт» — следующий шаг

- В профиле. Подтверждение паролем. Удаление — событие `UserDeleted` (каждый сервис удаляет данные человека).
- Обычный пользователь — одно подтверждение.
- Тренер с клиентами без аккаунта — двойное: второе окно со списком клиентов, которые удалятся вместе с ним,
  кнопка «Удалить» заблокирована несколько секунд (обратный отсчёт), чтобы успеть прочитать.
